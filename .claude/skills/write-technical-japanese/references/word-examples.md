## 利用方針

このデータセットを、開発者向け文書で語を選ぶ際の候補として使う。語の意味、確度、因果関係、主体、時制を確認し、文脈に合う語だけを選ぶ。ユーザー指定、リポジトリの用語、製品の正式名称を優先する。

語彙例は必須語や禁止語ではない。同じ概念には同じ語を使い、表現の変化だけを目的とした言い換えは避ける。参照元の文や固有の語り口は再現しない。

語を具体化するだけの目的で、処理順、データフロー、制御条件、回数の上限や下限、対象範囲を推測しない。複数の語が異なる仕様を表す場合は一つに決めず、元の表現を保つか不足情報を確認する。

## 文書内の位置

| 役割 | 語彙例 | 用途 |
| --- | --- | --- |
| 文書全体 | 本稿、本記事、本書 | 文書そのものを指す場合 |
| 現在の区分 | 本節、本項 | 現在の見出し範囲を指す場合 |
| 後続内容 | 以下、後述 | 直後または後の内容を指す場合 |
| 先行内容 | 前述、先ほど | 対応する箇所が明確な場合 |
| 対象 | 対象、該当箇所、当該処理 | 指示語だけでは参照先が曖昧な場合 |

`これ`、`それ`、`上記`、`下記`だけで参照先が曖昧になる場合は、対象の名詞を示す。

### 名詞の使い分け

| 名詞 | 基本的な意味 |
| --- | --- |
| 要件 | 満たす必要がある要求や条件 |
| 仕様 | 外部から観察できる動作や取り決め |
| 設計 | 要件や仕様を実現する構成や方針 |
| 実装 | 設計を具体化したコードや仕組み |
| 現象 | 観察された状態や挙動 |
| 原因 | 現象を生じさせたと確認できる要因 |
| 影響 | 現象によって利用者やシステムに生じる結果 |
| 障害 | 期待されるサービスや機能を提供できない状態 |
| 不具合 | 実装や製品が期待される動作と一致しない問題 |
| エラー | 処理の失敗、異常状態、またはその通知 |

原因が未確認の場合は「原因」ではなく「原因候補」や「仮説」を使う。入力で用語が定義されている場合は、その定義を優先する。

## 技術関連の動詞

### 調査と理解

| 意図 | 動詞例 | 選択基準 |
| --- | --- | --- |
| 状態を見る | 確認する、観察する | 成否や値は「確認」、継続的な挙動は「観察」 |
| 情報を集める | 調査する、収集する | 原因や仕組みは「調査」、資料や値は「収集」 |
| 中身を調べる | 解析する、分析する | 構造や挙動は「解析」、傾向や関係は「分析」 |
| 正しさを確かめる | 検証する、再現する | 仮説や結果は「検証」、同じ現象は「再現」 |
| 違いを見る | 比較する、照合する | 複数対象は「比較」、基準との一致は「照合」 |
| 対象を絞る | 特定する、選定する | 対象を突き止める場合は「特定」、候補から選ぶ場合は「選定」 |
| 情報を分ける | 抽出する、分類する、整理する | 一部を取り出す、種類で分ける、関係を整える場合 |
| 内容を読む | 参照する、確認する | 資料を根拠として使う場合は「参照」 |

### 実装と操作

| 意図 | 動詞例 |
| --- | --- |
| 処理を動かす | 実行する、起動する、呼び出す |
| データを得る | 取得する、受信する、読み取る |
| データを渡す | 送信する、返す、出力する |
| データを残す | 保存する、格納する、記録する |
| 内容を変える | 更新する、変更する、置換する、変換する |
| 対象を加える | 追加する、登録する、挿入する |
| 対象を除く | 削除する、除外する、破棄する |
| 値を決める | 設定する、指定する、割り当てる |
| 対象をつなぐ | 接続する、連携する、関連付ける |
| 利用を認める | 許可する、有効にする |
| 利用を止める | 拒否する、無効にする、遮断する |

`行う`、`処理する`、`対応する`で操作内容が不明確になる場合は、対象に合う具体的な動詞を使う。

| 意図 | 動詞例 |
| --- | --- |
| 入力を受ける | 受け付ける、受信する、読み込む |
| 構造を解釈する | 解析する、パースする、デコードする |
| 表現を変える | 変換する、エンコードする、正規化する |
| 妥当性を確かめる | 検証する、照合する、検査する |
| 危険な入力を扱う | サニタイズする、エスケープする、除去する |
| 形式を保存向けにする | シリアライズする |
| 保存形式から戻す | デシリアライズする |
| 一時的に保持する | キャッシュする、蓄積する、保持する |

英語由来の動詞と日本語の動詞は、文書内で一方に統一する。ただし、API やライブラリの正式な操作名は保つ。

## 順序と追加

| 関係 | 接続例 | 用途 |
| --- | --- | --- |
| 開始 | まず、はじめに | 最初の操作または前提 |
| 継続 | 次に、その後 | 時系列または手順の続き |
| 終了 | 最後に | 最終操作がある場合 |
| 並列 | また、加えて | 同じ重要度の情報の追加 |
| 補足 | なお、補足として | 本筋を変えない情報の追加 |

順序が自明な短い文章では、接続語を省く。

## 対比と例外

| 関係 | 接続例 | 用途 |
| --- | --- | --- |
| 逆接 | しかし、一方で | 先行内容と異なる事実 |
| 対応 | これに対して | 先行内容への処置や別の挙動 |
| 制限 | ただし | 条件、例外、注意点 |
| 譲歩 | それでも、にもかかわらず | 条件に反する結果 |
| 選択 | または、いずれか | 排他的かどうかを明確にした選択肢 |

対比がない箇所に逆接を置かない。例外は対象となる規則の直後に置く。

## 原因と結果

| 関係 | 表現例 | 強さ |
| --- | --- | --- |
| 直接原因 | 〜ため、〜に起因して | 原因が確認されている場合 |
| 根拠 | 〜ことから、〜に基づいて | 観察や仕様から判断する場合 |
| 結果 | そのため、結果として | 前の事実から結果が生じた場合 |
| 作用 | これにより、〜によって | 手段や変更が結果へ作用する場合 |
| 論理的帰結 | したがって、よって | 前提から結論を導ける場合 |
| 目的 | 〜するため、〜を目的として | 意図を示す場合 |

時系列だけでは因果を示さない。原因が未確認の場合は、確度の表現を加える。

## 条件と範囲

| 意図 | 表現例 |
| --- | --- |
| 条件 | 〜場合、〜とき、〜であれば |
| 必須条件 | 〜する必要がある、〜を前提とする |
| 限定 | 〜に限る、〜だけ、〜のみ |
| 例外 | 〜を除く、〜でない限り |
| 範囲 | 〜を対象とする、〜の範囲内、〜以降 |
| 上限と下限 | 最大、最小、以上、以下、超過、未満 |

「以上」と「超過」、「以下」と「未満」を区別する。条件を示す文では、条件と結果の対応を一意にする。

## 確度と根拠

| 確度 | 表現例 | 使用条件 |
| --- | --- | --- |
| 確認済み | 確認した、判明した、再現した | 根拠や検証結果がある場合 |
| 観察結果 | 〜が分かる、〜を示す、〜と確認できる | 出力、仕様、測定から読める場合 |
| 推論 | 〜と考えられる、〜と推測される | 根拠から推論する場合 |
| 可能性 | 〜可能性がある、〜おそれがある | 未確認の結果を示す場合 |
| 外観 | 〜ように見える、〜と思われる | 観察だけで確定できない場合 |
| 未確認 | 未確認、要確認、判断できない | 情報が不足している場合 |

根拠がない内容を「明らか」「当然」「確実」と表現しない。入力より断定を強めたり弱めたりしない。

## 影響と安全性

| 意図 | 語彙例 |
| --- | --- |
| 影響 | 影響する、到達する、波及する、阻害する |
| 情報 | 読み取り、書き込み、漏えい、窃取、改ざん |
| 権限 | 認証、認可、権限昇格、アクセス制御 |
| 入力 | 検証、サニタイズ、エスケープ、正規化 |
| 回避 | 回避する、バイパスする、悪用する |
| 防止 | 制限する、遮断する、緩和する、修正する |
| 公開状態 | 公開、非公開、修正済み、未修正 |
| 検証状態 | 再現済み、未検証、潜在的 |

セキュリティ用語を一般語へ置き換えて意味を広げない。攻撃可能性、実証の有無、許可範囲、修正状態を区別する。

## 冗長語の見直し

| 見直す表現 | 候補 | 判断基準 |
| --- | --- | --- |
| 〜することができます | 〜できます | 意味と確度が変わらない場合 |
| 〜を行います | 具体的な動詞 | 操作を特定できる場合 |
| 〜に関して | 〜について、対象を示す助詞 | 文を短くできる場合 |
| 〜において | 〜で | 場所や範囲の意味を保てる場合 |
| 〜という | 省略、名詞への直接接続 | 引用、定義、名称でない場合 |
| もの、こと | 具体的な名詞または動詞 | 対象や操作を特定できる場合 |
| さまざま、いろいろ | 複数、対象の列挙 | 範囲を具体化できる場合 |
| 基本的に、原則として | 条件の明示または省略 | 例外の有無を確認できる場合 |

短縮によって条件、法的意味、仕様上の意味、丁寧さが変わる場合は置換しない。
